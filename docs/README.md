# 文档目录

日常开发从 [工作须知](工作须知.md)、[项目交接](交接文档.md) 和 [L1 项目地图](../L1.md) 开始；按任务进入相关模块。运行命令以 [项目 README](../README.md) 为准，实际接口、状态和默认参数由源码与模块 L2 维护。

## 历史记录与验收证据

历史资料统一放在 [archive 目录](archive/README.md)：两份早期调研／讨论、首轮审查报告、已完成修复方案、验收记录，以及从 chat 方案拆出的设计比较。它们保留原始证据和决策来源，不需要默认通读，也不作为当前待办清单。

保留历史正文和来源引用；不将历史命令、测试数量、提交状态或候选参数当作当前运行依据。准确的当前状态从交接进入，阶段验收按交接指向的记录查看。
