# L2 — 应用与启动

上层入口：[L1](../L1.md)。应用当前实现本人专用的“你好 → 收到”收发验证。独立的 [chat 模块](chat/L2.md) 管理模型调用与聊天历史，尚未装配进微信应用。

## 职责、契约与状态

- `InboundText` 提供消息标识、发送者、文本及不透明回复句柄；`TextChannel` 提供接收、回复、释放句柄和游标检查点。应用不读取微信协议字段或模型 SDK 对象。
- 应用使用渠道登录得出的本人身份；只接受本人去掉两端空白后的“你好”。回复固定为“收到”，没有开放访问或自动认领首个联系人。
- 同条消息在当前进程去重；记录仅含身份与消息标识，最多一天、一万条。发送失败或结果未知也不自动重发相同入站消息；新消息可以继续处理。
- 渠道返回统一发送回执：`accepted` 为接口明确成功，`submitted` 为提交完成但无明确成功码；均不代替手机实际送达确认，后者也不触发自动重发。
- 一批消息按顺序处理后才请求渠道保存游标。普通接收失败退避，认证失效退出，取消信号传递至请求与等待。当前固定回复耗时短，尚无模型任务队列。
- 配置检查只读、离线；启动装配负责进程信号、登录、单实例与生命周期通知。
