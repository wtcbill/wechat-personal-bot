# L2 — 微信 iLink 渠道（weixin_ilink）

上层入口：[应用地图](../L2.md)、[项目 L1](../../L1.md)。本区域封装腾讯 iLink 的登录、文本收发与渠道状态，不调用模型、不管理模型历史。

## 输入输出与边界

- 登录从固定腾讯地址获取二维码；登录结果必须包含 Bot token、Bot 身份及扫码者身份，后者成为唯一允许的用户。
- 消息转换拒绝群、Bot 自发消息、错误接收者、无稳定标识、无回复令牌和非纯文本。应用仅收到统一文本对象；回复令牌由本区域通过不透明句柄保管，处理结束即释放。
- 只向已绑定的本人发送；回复携带对应入站的 `context_token`，每次发送生成独立 `client_id`。接口返回 `ret: 0` 或 `errcode: 0` 时报告明确接受；HTTP/JSON 提交成功但没有成功码时报告已提交，不将可选回执缺失当作错误。明确错误码仍失败；所有回执都与手机实际送达分开。
- HTTP 错误和业务错误只输出安全代码，不保留服务端错误正文；请求禁止隐式重定向。登录跳转和 API 地址限定 HTTPS 的 `.weixin.qq.com` 子域，防止凭据转交其他主机。
- 普通请求与长轮询均支持超时和取消；轮询超时为空批次；认证错误停止轮询。退出通知仅作尽力发送。

## 状态与失败行为

- `ChannelState` 在项目 `.weave/` 保存凭据、账号绑定的游标和进程锁，不保存聊天正文。写入使用临时文件和替换。
- 二维码图片是本机登录入口；过期后重新登录。需要验证码时在运行终端输入，不写入配置或日志。
- 重新登录清空游标；应用处理完一批后保存新的非空游标。游标保存失败时本进程去重可避免通常的重复处理；进程崩溃窗口不保证恰好一次。
- 单实例锁阻止并行进程；已退出进程遗留的锁可在确认 PID 不存在后清理。不会终止其他进程。
