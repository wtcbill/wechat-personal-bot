# Weave

以个人微信聊天窗口作为自然语言交互终端，通过 iLink 接入应用，远程使用部署侧的工具与服务。应用独立于具体后端，各服务按独立模块接入。

首版只接入 DS API（DeepSeek API），先跑通微信文本问答；DSH、SSH 远程执行和其他后端在后续版本接入。具体范围、模块隔离与验收条件以 [首版方案](docs/首版方案.md) 为准。

## 当前状态

当前已建立独立 Git 仓库、开发规则、GEB 导航和首版方案，尚无业务代码、依赖声明、运行配置或可执行测试。语言、技术栈、具体模块目录和接口签名仍待讨论确定。

Weave 与旧实现独立维护。已沿用旧项目的开发约束和 GEB 维护规则，旧业务代码是否沿用后续逐项决定；旧实现地图与历史测试结果不作为本项目的实现或验证结论。
